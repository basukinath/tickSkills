📤 Bulk Import Questions

ℹ️ Import Guidelines:
  • Upload a JSON file with an array of questions
  • Each question must have: title, slug, difficulty, category, source, tags
  • Duplicate titles will be skipped automatically
  • Categories and tags will be auto-created if they don't exist
  • Maximum recommended: 5,000 questions per import
📋 JSON Format Example ▼ 
[
  {
    "id": 1,
    "title": "Two Sum",
    "slug": "two-sum",
    "difficulty": "Easy",
    "category": "Arrays & Hashing",
    "source": "LEETCODE",
    "external_url": "https://leetcode.com/problems/two-sum/",
    "is_active": true,
    "is_premium": false,
    "acceptance_rate": 52.5,
    "companies": ["Amazon", "Microsoft", "Google"],
    "tags": ["Array", "Hash Table"]
  },
  {
    "id": 2,
    "title": "Add Two Numbers",
    "slug": "add-two-numbers",
    "difficulty": "Medium",
    "category": "Linked List",
    "source": "LEETCODE",
    "external_url": "https://leetcode.com/problems/add-two-numbers/",
    "is_active": true,
    "is_premium": false,
    "acceptance_rate": 42.3,
    "companies": ["Amazon", "Apple"],
    "tags": ["Linked List", "Math", "Recursion"]
  }
]
📝 Field Descriptions:
  • id (optional): External reference ID
  • title (required): Question title (used for duplicate detection)
  • slug (required): URL-friendly identifier
  • difficulty (required): Must be "Easy", "Medium", or "Hard"
  • category (required): Category name (auto-created if needed)
  • source (required): Must be "LEETCODE", "HACKERRANK", or "GFG"
  • external_url (optional): Link to original question
  • is_active (optional): Boolean, defaults to true
  • is_premium (optional): Boolean, indicates premium content
  • acceptance_rate (optional): Number (percentage)
  • companies (optional): Array of company names
  • tags (required): Array of tag names (auto-created if needed)
